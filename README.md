# 호프(HOPE) 최종 관객수 예측 리포트

KOBIS 데이터를 근거로 영화 '호프(HOPE)'의 최종 누적 관객수를 best / base / worst 세 시나리오로
예측하는 로컬 정적 리포트다. 실시간 대시보드(`../hope-dashboard`)와는 완전히 분리된 프로젝트다.

## 실행 방법

### 1. 데이터 수집 (최초 1회, 몇 분 소요)

```
node --env-file=.env collect.js
```

2023-01-01부터 오늘까지 KOBIS 일별 박스오피스(top20)를 순회 수집해 `data/boxoffice-cache.json`에
저장한다. 실패한 날짜는 자동으로 재시도되며, 스크립트를 다시 실행하면 이미 캐시된 날짜는 건너뛰고
실패했던 날짜만 재시도한다(idempotent).

### 2. 분석 실행

```
node --env-file=.env analyze.js
```

캐시에서 비교군을 추출하고 배수·예측 궤적을 계산해 `data/analysis.json`을 생성한다. 동시에
같은 데이터를 `index.html` 안에도 직접 내장(embed)한다.

### 3. 리포트 열기

`index.html`에 분석 데이터가 내장되어 있으므로 **서버 없이 파일 탐색기에서 더블클릭하면 바로 열린다**
(`file://`로 열어도 정상 동작). 별도 서버 구동이 필요 없다.

정적 서버로 구동해도 물론 동작한다(예: `npx serve .`) — `index.html`은 내장 데이터가 있으면
그것을 우선 사용하고, 없을 경우에만 `fetch`로 `data/analysis.json`을 읽는다.

## 데이터 최신화

호프의 최신 실적을 반영하려면 `collect.js`를 다시 실행(오늘 날짜가 자동으로 추가 수집됨)한 뒤
`analyze.js`를 재실행하면 된다. `analyze.js`가 `data/analysis.json`과 `index.html` 내장 데이터를
함께 갱신하므로, 그 다음 `index.html`을 다시 열기만 하면 최신 예측치가 보인다.

## 방법론 요약

2023-01 이후 개봉한 한국영화 중 누적 500만 명 이상을 기록하고 흥행이 종료된 작품들을 비교군으로
삼는다. 각 작품의 "개봉 후 D일차(호프의 현재 경과일) 누적관객수 대비 최종 누적관객수" 배수를 구하고,
장르(SF/스릴러/액션 일치도 45%) · 개봉 규모(첫날 스크린 수 유사도 35%) · 개봉 시기(여름 성수기
근접도 20%)로 가중치를 부여한다. 가중 배수 분포의 25/50/75 백분위수를 각각 worst/base/best로
사용하며, 이 배수를 호프의 현재 누적관객수에 곱해 최종 관객수를 추정한다. 60일 예측 궤적은 유사도
상위 비교군들의 정규화 흥행 곡선을 가중 평균해 현재 실측치에서 자연스럽게 이어지도록 보정한 것이다.

## 알려진 한계

- KOBIS 무료 API는 날짜별 박스오피스 **상위 20위까지만** 제공한다. 순위권 밖으로 밀려난 날짜의
  관객수는 확인 불가 — 마지막 관측치로 이월(carry-forward) 처리했다. 리포트의 "데이터 커버리지"
  컬럼에서 관측 비율을 확인할 수 있다.
- "흥행 종료" 판정은 마지막으로 차트에 관측된 날짜로부터 오늘까지 14일 이상 공백이 있는지로
  판단한다(`analyze.js`의 `FINISHED_GAP_DAYS`). 최근까지 장기 흥행 중인 영화(예: 개봉 후 몇 달째
  차트에 남아있는 작품)는 최종치가 아직 확정되지 않았다고 보고 비교군에서 제외한다.
- 예측치는 과거 유사 흥행작들의 통계적 패턴에 기반한 추정이며, 실제 최종 관객수를 보장하지 않는다.

## 파일 구조

```
collect.js              KOBIS 일별 박스오피스 수집 스크립트
analyze.js               비교군 추출·예측 계산 스크립트 (data/analysis.json 생성 + index.html에 데이터 내장)
index.html               반응형 리포트 (단일 파일, 분석 데이터 내장 — file://로 바로 열림)
data/boxoffice-cache.json   수집 원본 캐시 (gitignore, 재실행으로 재생성 가능)
data/analysis.json          분석 결과 원본 (참고/디버깅용, index.html은 내장 데이터를 우선 사용)
.env                     KOBIS_API_KEY (gitignore)
```
